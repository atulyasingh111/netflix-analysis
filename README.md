# Netflix Revenue & Subscriber Analytics (2019–2024)

An Excel-based business analytics project analyzing Netflix’s financial performance, subscriber growth, profitability, regional expansion, and quarterly trends from 2019–2024.

## Project Overview

This project explores Netflix's:
- Revenue growth
- Subscriber dynamics
- Profitability trends
- Regional performance
- Content cost strategy
- Quarterly seasonality patterns

The analysis was conducted using Microsoft Excel with dashboards, KPI tracking, charts, and financial modeling techniques.

## Tools & Skills Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- KPI Dashboards
- Data Cleaning
- Financial Analysis
- Business Analytics
- Trend Analysis

---

## Key Insights

- Revenue grew from **$20.2B (2019)** to **$38.9B (2024)**
- Subscribers increased from **167.1M** to **301.6M**
- APAC recorded the fastest subscriber growth
- 2022 showed profitability decline due to rising content costs
- 2023–2024 recovery driven by ad-supported plans and password-sharing enforcement
